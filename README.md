# Techly Project

This project is structured with a separate frontend and backend for better architectural separation.

## Project Structure

- **`frontend/`**: The Next.js 15 application.
- **`backend/`**: Placeholder for future server-side development.

## Getting Started

To run the frontend development server from the root, use:

```bash
npm run dev:frontend
```

Alternatively, you can navigate into the `frontend` directory:

```bash
cd frontend
npm run dev
```

## Architecture
- **Frontend**: Next.js, OGL (WebGL), Tailwind CSS.
- **Status**: Core landing page implementation complete with 3D procedural visuals and AI interaction elements.
